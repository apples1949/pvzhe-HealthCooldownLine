# pvzhe-HealthCooldownLine
在角色血条上方显示关键事件数值（可多行并存、每行独立颜色）：  
① 加农炮装填剩余  
② 命名计时器倒计时  
③ 土豆雷准备出土  
④ 篮球剩余投抛数（仅真弹药角色）  
⑤ 投石车剩弹  
⑥ 坑洞消失倒计时  
⑦ 大嘴花咀嚼时间  
⑧ 长大倒计时  
⑨ 周期区域事件触发倒计时  
⑩ 磁力消化倒计时  
⑪ 阳光/金币/卡包产出倒计时  
⑫ 蓄能咖啡豆充能倒计时。  
叠种兼容：同格多角色显示行自动错开。含候选缺组件诊断（日志可见）。战斗设置页「显示冷却倒计时」开关位于血条开关右列顶部。
